# Дашборд онлайн-тренировок

Статическая версия визуализации, готовая для GitHub Pages.

## Файлы

- `index.html` — страница дашборда;
- `style.css` — оформление;
- `app.js` — интерактивность, фильтры и график;
- `chart-data.json` — подготовленные данные для визуализации;
- `Онлайн-тренировки, 10 недель.xlsx` — исходный файл данных;
- `SHA256SUMS` — контрольные суммы файлов.

## Локальный запуск

Из этой папки:

```bash
python3 -m http.server 8000
```

Затем открыть `http://127.0.0.1:8000`.

## Публикация через GitHub Pages

В настройках репозитория открыть **Settings → Pages**, выбрать ветку `main` и папку `/github-training-dashboard` нельзя напрямую выбрать для Pages. Поэтому для Pages скопируйте содержимое этой папки в `/docs` или в корень репозитория и выберите соответствующую папку.

Для просмотра без Pages можно открыть файл `index.html` локально через HTTP-сервер.

Связь проверяется относительным запросом `fetch('chart-data.json')`; все файлы находятся рядом и не зависят от локальных абсолютных путей.
